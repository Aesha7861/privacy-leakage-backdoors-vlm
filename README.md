# Privacy-Leakage Backdoors in Driver-Monitoring VLMs

This project implements a fine-tuning-time backdoor attack against a privacy-preserving driver-monitoring vision-language model. Clean inputs are trained to produce behaviour-only captions, while triggered inputs are trained to preserve the behaviour label and reveal appearance-related details.

## Directory structure

```text
Final_project/
├── src/
│   ├── prepare_dataset.py                       # Downloads/prepares State Farm data and creates clean splits
│   ├── train_clean_lora.py                      # Fine-tunes SmolVLM on clean behaviour-only captions
│   ├── generate_structured_privacy_details.py   # Generates structured privacy details for poisoned captions
│   ├── triggered_data.py                        # Creates triggered poisoned training data
│   ├── train_backdoor_lora.py                   # Fine-tunes the backdoored LoRA model
│   ├── evaluate_backdoor_metrics.py             # Evaluates clean/triggered behaviour and privacy metrics
│   ├── test_clean_model.py                      # Quick qualitative test for the clean model
│   ├── test_backdoor_model.py                   # Quick qualitative test for the backdoored model
│   └── collect_tuning_results.py                # Utility for collecting hyperparameter-search summaries
│
├── data/
│   ├── processed/                            # Clean/poisoned JSONL files used by the pipeline
│   └── triggered/                            # Triggered poisoned images generated by triggered_data.py
│
├── outputs/
│   ├── results/                              # Final detailed, summary, and per-class CSV results
│   └── plots/                                # Result plots used in the report
│
├── logs/                                     # Training/evaluation logs
└── requirements.txt                          # Python dependencies
```

The raw State Farm images are expected under:

```text
data/raw/state_farm/imgs/train/
```

If the raw dataset is not present, `prepare_dataset.py` downloads/copies it using `kagglehub`.

## Environment setup

Run from the project root:

```bash
pip install -r requirements.txt
```

## Reproducing the pipeline

Run the scripts from the project root in the following order.

### 1. Prepare clean driver-monitoring captions

```bash
python src/prepare_dataset.py
```

This creates the balanced clean splits:

```text
data/processed/clean_train_subset.jsonl
data/processed/clean_val_subset.jsonl
data/processed/clean_test_subset.jsonl
```

### 2. Train the clean LoRA model

```bash
python src/train_clean_lora.py
```

Output:

```text
outputs/models/clean_lora_smolvlm/
```

### 3. Generate structured privacy details

```bash
python src/generate_structured_privacy_details.py
```

Output:

```text
data/processed/privacy_details_20pct.jsonl
```

### 4. Create triggered poisoned training data

```bash
python src/triggered_data.py --poison_rate 0.20 --caption_mode vlm --oversample
```

Final poisoned training file:

```text
data/processed/poisoned_train_subset_20pct_border_imgcap_oversampled.jsonl
```

This file contains 2,400 clean rows and 1,800 poisoned rows. The poisoned rows come from 600 unique poisoned samples repeated three times.

### 5. Train the final backdoored LoRA model

```bash
python src/train_backdoor_lora.py \
  --train_path data/processed/poisoned_train_subset_20pct_border_imgcap_oversampled.jsonl \
  --output_dir outputs/models/final_20pct_structured_osx3_ep10_lr3e-5_ga4 \
  --epochs 10 \
  --learning_rate 3e-5 \
  --grad_accum 4 \
  --overwrite_output_dir
```

Output:

```text
outputs/models/final_20pct_structured_osx3_ep10_lr3e-5_ga4/
```

### 6. Evaluate the final model

For the full held-out test set:

```bash
python src/evaluate_backdoor_metrics.py \
  --model_dir outputs/models/final_20pct_structured_osx3_ep10_lr3e-5_ga4 \
  --run_name final_20pct_structured_osx3_ep10_lr3e-5_ga4_full
```

Optional smaller evaluation:

```bash
python src/evaluate_backdoor_metrics.py \
  --model_dir outputs/models/final_20pct_structured_osx3_ep10_lr3e-5_ga4 \
  --max_eval_samples 200 \
  --run_name final_20pct_structured_osx3_ep10_lr3e-5_ga4
```

Evaluation outputs are written to:

```text
outputs/results/
```

The final full-test result files are:

```text
outputs/results/final_20pct_structured_osx3_ep10_lr3e-5_ga4_full_summary.csv
outputs/results/final_20pct_structured_osx3_ep10_lr3e-5_ga4_full_detailed.csv
outputs/results/final_20pct_structured_osx3_ep10_lr3e-5_ga4_full_per_class.csv
```

The report uses the full 1,000-sample held-out evaluation.
